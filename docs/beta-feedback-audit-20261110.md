## 缩略图独立测量

真实 Chromium 经本机 HTTP 加载并解码 4 张独立合成的 2560×1440 JPEG，每种方式 3 次，跳过浏览器缓存。原图合计 12,476,381 bytes，缩略图 30,993 bytes，下降 99.75%；加载加解码中位耗时分别 157.1ms / 84.8ms。已核对页面实际使用缩略图 URL，390px 视口没有横向溢出。

这说明本次缩略图可减少传输量，不能外推为生产公网延迟或服务器容量结论。测量 JSON 与桌面、移动端截图保存在本工作区 `work/feedback-audit/`。
