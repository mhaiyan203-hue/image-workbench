# 套图提示词编辑

修改用户指定的场景、镜头、构图、光线或真实文案。保留商品事实、当前图片用途和统一风格；不把整套十五张塞进一张拼图。

全套使用同一位成年虚构模特，固定脸型、发型、体型与肤色。若有模特参考图，以模特参考为准；否则采用自然黑发、简洁妆容的成年东亚模特。服装必须穿着展示，微距可仅保留身体局部。

不补造缺失的尺寸、认证、功效、背面结构、Logo或包装。修改结果为可编辑的单张图片提示词，不提交生成、不改变套餐价格与张数。
